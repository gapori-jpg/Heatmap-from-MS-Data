# Heatmap-from-MS-Data
### Abstract:
Cardinal MSI is an open source mass spectrometry imaging (MSI) software that could support numerous space exploration and mission teams. Specializing in statistical analysis, Cardinal MSI produces results similar, and equally significant, to the current Bruker software. However, in the case access to Bruker software is limited, this code serves as an alternative. The objective of this paper is to explore how R Studio and CodeHS can visualize, analyze, and present Mass Spectrometry (MS) data through R and Python code. 

### Installation Guide and Code for Cardinal MSI:
As aforementioned, Cardinal MSI is an open source MSI software. In order to access its full libraries, however, applying it to standard R environments, like [R Studio], is essential. R Studio is an integrated development environment (IDE) that processes code and produces imagery.  
[Here] is a link to the Installation guide.
The R code was made in collaboration with Google and R documentation. While this code, along with the CodeHS code, is catered to the collection of MS data for the Dragonfly Mass Spectrometer (DraMS) team, it remains relevant for the general interpretation and analysis of chemical data.

### Installation Guide and Code for CodeHS Heatmap:
[CodeHS] is a coding platform used in many high school computer science classes. Its various Python Sandbox environments ensure general accessibility to adequate software at no additional cost. Just as this type of website has been applied to high school classes, it can be integrated to optimize mission specific workflow.
[Here] is a link to the Installation guide.

### Conclusions:
This code is expected to be useful in the testing during and data collection after the launching of Dragonfly. Simultaneously, this code can be adapted and customized to benefit chemical analysis.
